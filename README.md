# Olafgeibig Tools

## How do I install these formulae?

`brew install olafgeibig/tools/<formula>`

Or `brew tap olafgeibig/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "olafgeibig/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
